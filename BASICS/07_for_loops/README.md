# FOR LOOPS

A `for` loop is really good when you know WHAT you want to loop through.

## RANGE

```python
for i in range(5):
    print(i)
```

Prints:

```text
0
1
2
3
4
```

`i` is just a variable.

You could name it something else:

```python
for potato in range(5):
    print(potato)
```

Please do not do this in normal code unless you want me to judge you.

## LOOP THROUGH TEXT

```python
name = "Foxz"

for letter in name:
    print(letter)
```

## WHEN DO I USE FOR VS WHILE?

Usually:

`for`
- repeat a known amount
- go through a collection of things

`while`
- keep going until something changes
