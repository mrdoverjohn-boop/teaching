# TEACHING ROADMAP

You already have:

1. `01_print`
2. `02_variables`
3. `03_input`

Recommended next order:

4. `04_math_and_types`
5. `05_if_statements`
6. `06_while_loops`
7. `07_for_loops`
8. `08_lists`
9. `09_functions`
10. `10_random`

After `05_if_statements`, start giving tiny projects.

After `06_while_loops`, they can make:
- number guessing games
- tiny text adventures
- basic menus
- clicker-ish terminal games

After `10_random`, DO THE 30 MINUTE GAME CHALLENGE.

Do not make them memorize everything.
The point is:
- explain one thing
- make them use it
- make them break it
- make them fix it
- then build something stupid with it
