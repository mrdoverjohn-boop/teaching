# THEME ROULETTE

**Difficulty:** 🟡 Early  
**Recommended time:** 30 minutes  
**Players:** 2+  
**Recommended prerequisites:** basic game building  

---

# RULES

- Create three lists: setting, mechanic, mood.
- Randomly draw one from each.
- Everyone must combine all three into a game.
- No rerolls unless the combination is literally impossible.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Theme Use
- Creativity
- Fun
- Completeness
- Polish

---

# WHAT THIS SECRETLY TEACHES

- rapid ideation
- adaptation

---

# OPTIONAL VARIANT

Each team gets a different random combination.
