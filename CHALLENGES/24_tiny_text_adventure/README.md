# TINY TEXT ADVENTURE

**Difficulty:** 🟡 Early  
**Recommended time:** 30 minutes  
**Players:** 1+  
**Recommended prerequisites:** if, loops, lists  

---

# RULES

- Create at least 5 locations.
- Player can move between them.
- At least one item or event is required.
- There must be a win condition.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- World
- Navigation
- Mechanics
- Fun
- Completeness

---

# WHAT THIS SECRETLY TEACHES

- state
- branching
- menus

---

# OPTIONAL VARIANT

One room changes after the player visits another room.
