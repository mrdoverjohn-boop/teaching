# MYSTERY VARIABLE

**Difficulty:** 🟢 Beginner  
**Recommended time:** 20 minutes  
**Players:** 2+  
**Recommended prerequisites:** variables, input, math  

---

# RULES

- One person writes a tiny program with one hidden starting value.
- Other players can run the program and inspect outputs but not the source.
- They must figure out the hidden value or rule.
- Then swap roles.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Puzzle Quality
- Solvability
- Creativity
- Clarity
- Fewest Guesses

---

# WHAT THIS SECRETLY TEACHES

- reasoning about state

---

# OPTIONAL VARIANT

Hide a formula instead of a single value.
