# WHO CAN MAKE THE BEST GAME IN 30 MINUTES?

## THE MATCH

### TEAM PYTHON
The beginners.

They may:
- use Python
- work together
- share ideas/code with each other
- use the lesson repository
- use Python's built-in documentation / help

### TEAM SUFFERING
Bramity.

Rules:
- works ALONE
- must use Rust OR C
- cannot switch to Python
- same 30 minute timer

Recommended handicap language: **Rust**.

C is funny, but Rust gives you enough structure and tooling that you can probably
finish something instead of spending 11 minutes fighting strings.

## BEFORE THE TIMER

Everyone gets 5 minutes BEFORE the challenge to:

- create/open the project
- make sure the language runs
- open the editor
- no game logic yet

The 30 minute timer starts when everyone can actually code.

## THE THEME

Choose ONE theme right before starting.

Ideas:

- ESCAPE
- ONE BUTTON
- CATS
- SPACE
- GREMLINS
- DUNGEON
- YOU ARE THE ENEMY
- EVERYTHING IS BROKEN
- SPEED
- DON'T TOUCH IT

Everyone must make a game somehow related to the same theme.

## WHAT COUNTS AS A GAME?

It must have:

1. player input
2. a goal
3. a way to win, lose, or finish
4. some kind of decision / mechanic

A terminal game COUNTS.

Do not waste the entire challenge trying to make graphics if nobody knows graphics yet.

## SCORING — 25 POINTS

After the timer ends, everyone plays every game.

Score each game from 0–5 in:

### FUN — /5
Was it actually enjoyable?

### CREATIVITY — /5
Did they do something interesting or stupid in a good way?

### COMPLETENESS — /5
Does it feel like an actual finished tiny game?

### POLISH — /5
Instructions, readable output, fewer bugs, nice little touches.

### TECHNICAL COOL SHIT — /5
Did they pull off something impressive for their language/experience?

## IMPORTANT

A technically complicated game is NOT automatically better.

If Team Python makes a stupid little game that is hilarious and actually works,
and Bramity spends 30 minutes implementing a gorgeous Rust architecture that has
no fucking game in it:

TEAM PYTHON SHOULD WIN 😭

## OPTIONAL CHAOS RULE

At the 15-minute mark, reveal ONE modifier:

- add a score system
- add a random event
- add a second ending
- add an NPC
- add an item
- add a secret
- add a timer/turn limit

Everyone gets the same modifier.

## NO POST-TIMER FIXES

When 30:00 hits:

HANDS OFF THE KEYBOARD.

If it crashes, you may restart it.

You may NOT fix it.

LET THE BUGS SPEAK FOR THEMSELVES.
