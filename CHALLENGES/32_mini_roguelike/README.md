# MINI ROGUELIKE

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 60 minutes  
**Players:** 1+  
**Recommended prerequisites:** functions, lists, random, loops  

---

# RULES

- Create rooms or encounters procedurally.
- Player gains or loses resources as they progress.
- Death or victory ends the run.
- Repeated runs should differ.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Replayability
- Progression
- Balance
- Fun
- Completeness

---

# WHAT THIS SECRETLY TEACHES

- procedural systems
- progression
