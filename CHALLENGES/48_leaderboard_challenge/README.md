# LEADERBOARD CHALLENGE

**Difficulty:** 🔴 Advanced  
**Recommended time:** 40 minutes  
**Players:** 2+  
**Recommended prerequisites:** file I/O, lists, sorting  

---

# RULES

- Build a score-based game.
- Store player names and scores.
- Show a sorted local leaderboard.
- Everyone plays everybody else's game once.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Leaderboard
- Game
- Polish
- Reliability
- Competition

---

# WHAT THIS SECRETLY TEACHES

- persistent data
- sorting

---

# OPTIONAL VARIANT

Keep only the top 5 scores.
