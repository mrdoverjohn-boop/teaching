# SECRET MECHANIC

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 40 minutes  
**Players:** 2+  
**Recommended prerequisites:** loops, functions, random  

---

# RULES

- Everyone gets the same public theme.
- Each person secretly receives one required mechanic.
- The mechanic must meaningfully affect gameplay.
- At the end, everyone tries to guess each player's secret mechanic.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Mechanic Integration
- Fun
- Creativity
- Completeness
- Theme Use
