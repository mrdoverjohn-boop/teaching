# WORST CALCULATOR EVER

**Difficulty:** 🟢 Beginner  
**Recommended time:** 20 minutes  
**Players:** 1+  
**Recommended prerequisites:** input, variables, math  

---

# RULES

- Make a calculator that technically works.
- It must intentionally have a ridiculous personality.
- Support at least 4 operations.
- It may insult bad input, but it still needs to handle it sensibly.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Works
- Personality
- Operations
- Error Handling
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- input conversion
- operators

---

# OPTIONAL VARIANT

Make it act like it hates one specific number.
