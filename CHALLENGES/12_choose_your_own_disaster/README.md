# CHOOSE YOUR OWN DISASTER

**Difficulty:** 🟢 Beginner  
**Recommended time:** 25 minutes  
**Players:** 1+  
**Recommended prerequisites:** input, if statements  

---

# RULES

- Create a short branching story.
- At least 5 meaningful choices are required.
- At least 3 endings are required.
- Choices must actually change what happens.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Choices
- Humor/Fun
- Endings
- Creativity
- Works Correctly

---

# WHAT THIS SECRETLY TEACHES

- branching logic
- writing decisions

---

# OPTIONAL VARIANT

Every ending must somehow involve the same object.
