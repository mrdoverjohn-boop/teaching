# TERMINAL BOSS FIGHT

**Difficulty:** 🟡 Early  
**Recommended time:** 30 minutes  
**Players:** 1+  
**Recommended prerequisites:** while, random, if statements  

---

# RULES

- Create a player and boss with health.
- Give the player at least 2 actions.
- Boss behavior must involve randomness.
- Game ends when one side reaches 0 health.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Combat
- Balance
- Fun
- Polish
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- game state
- turn loops

# OPTIONAL VARIANT
