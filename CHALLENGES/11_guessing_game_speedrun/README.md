# GUESSING GAME SPEEDRUN

**Difficulty:** 🟢 Beginner  
**Recommended time:** 15 minutes  
**Players:** 1+  
**Recommended prerequisites:** while loops, if statements, random  

---

# RULES

- Make a number guessing game.
- Tell the player too high or too low.
- Track number of guesses.
- Lowest bug-free completion time wins.

---
