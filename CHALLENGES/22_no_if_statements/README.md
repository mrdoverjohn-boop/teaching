# NO IF STATEMENTS

**Difficulty:** 🔴 Advanced  
**Recommended time:** 30 minutes  
**Players:** 1+  
**Recommended prerequisites:** functions, dictionaries/lists, confidence  

---

# RULES

- Build a tiny game without writing any if/elif statements.
- Ternary expressions are also banned.
- Use data structures, functions, exceptions, or other approaches.
- The game still needs real player choices.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Rule Compliance
- Creativity
- Works
- Readability
- Fun

- creative problem solving
