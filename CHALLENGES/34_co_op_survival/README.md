# CO-OP SURVIVAL

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 45 minutes  
**Players:** 2+  
**Recommended prerequisites:** game state, functions, loops  

---

# RULES

- Players share a common survival goal.
- Each player chooses an action every round.
- Actions should interact with shared resources.
- Everyone wins or loses together.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Team Decisions
- Balance
- Fun
- Mechanics
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- cooperative systems
- shared resources

---

# OPTIONAL VARIANT

Give each player one unique ability.
