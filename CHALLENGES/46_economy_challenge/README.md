# ECONOMY CHALLENGE

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 45 minutes  
**Players:** 1+  
**Recommended prerequisites:** math, lists, functions  

---

# RULES

- Build a small economy game.
- Player can earn and spend currency.
- Prices or income must change based on something.
- There must be a win condition based on money/resources.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Economy Design
- Balance
- Strategy
- Fun
- Completeness

---

# WHAT THIS SECRETLY TEACHES

- balancing
- simulation
