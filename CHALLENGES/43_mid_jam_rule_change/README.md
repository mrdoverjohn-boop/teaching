# MID-JAM RULE CHANGE

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 40 minutes  
**Players:** 2+  
**Recommended prerequisites:** adaptation, functions  

---

# RULES

- Start a normal game challenge.
- At halfway, reveal a major new rule.
- Examples: no combat, add trading, player cannot die, reverse the objective.
- Everyone must adapt their existing project.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Adaptation
- Final Design
- Fun
- Completeness
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- handling changing requirements

---

# OPTIONAL VARIANT

Reveal two smaller changes at different times.
