# ONE MECHANIC GAME

**Difficulty:** 🟡 Early  
**Recommended time:** 30 minutes  
**Players:** 1+  
**Recommended prerequisites:** loops, functions  

---

# RULES

- Pick exactly one main mechanic.
- Examples: dodge, trade, guess, race, collect, sneak.
- Build the entire game around making that one mechanic fun.
- Do not bury it under 20 unrelated systems.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Core Mechanic
- Fun
- Polish
- Creativity
- Focus

---

# WHAT THIS SECRETLY TEACHES

- core game design
- scope
