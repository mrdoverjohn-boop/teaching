# PASSWORD DUNGEON

**Difficulty:** 🟢 Beginner  
**Recommended time:** 20 minutes  
**Players:** 1+  
**Recommended prerequisites:** if/else, input  

---

# RULES

- The player faces multiple locked doors.
- Each door has a clue.
- Correct answers progress deeper into the dungeon.
- At least 4 doors are required.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Clues
- Branching
- Polish
- Creativity
- Correctness

---

# WHAT THIS SECRETLY TEACHES

- conditions
- branching

---

# OPTIONAL VARIANT

One clue must depend on an earlier answer.
