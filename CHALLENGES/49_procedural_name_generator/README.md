# PROCEDURAL NAME GENERATOR

**Difficulty:** 🟡 Early  
**Recommended time:** 25 minutes  
**Players:** 1+  
**Recommended prerequisites:** lists, random, strings  

---

# RULES

- Generate names from multiple random pieces.
- Create at least 3 categories like first-part, second-part, title.
- Generate at least 20 examples.
- Use the names inside a tiny game or character generator.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Variety
- Funny/Good Names
- Code Design
- Integration
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- combining data
- procedural generation
