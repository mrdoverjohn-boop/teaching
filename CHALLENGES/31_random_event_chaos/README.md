# RANDOM EVENT CHAOS

**Difficulty:** 🟡 Early  
**Recommended time:** 30 minutes  
**Players:** 1+  
**Recommended prerequisites:** random, lists, loops  

---

# RULES

- Create at least 10 random events.
- Events must change game state.
- At least 2 events should be rare.
- Player tries to survive or reach a goal.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Event Variety
- Balance
- Fun
- Replayability
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- event systems
- probability

---

# OPTIONAL VARIANT

Add one event that permanently changes future probabilities.
