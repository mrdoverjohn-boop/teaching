# FUNCTION FACTORY

**Difficulty:** 🟡 Early  
**Recommended time:** 25 minutes  
**Players:** 1+  
**Recommended prerequisites:** functions, parameters, return  

---

# RULES

- Build a program with at least 8 functions.
- Every function must have a real purpose.
- At least 3 must return a value.
- Avoid giant functions that do everything.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Function Design
- Readability
- Works
- Reusability
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- decomposition
- reusable functions

---

# OPTIONAL VARIANT

Maximum 8 lines per function.
