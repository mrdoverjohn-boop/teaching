# SHOPKEEPER SIMULATOR

**Difficulty:** 🟡 Early  
**Recommended time:** 35 minutes  
**Players:** 1+  
**Recommended prerequisites:** lists, functions, math  

---

# RULES

- Player starts with money and items for sale.
- Allow buying or selling.
- Track money and inventory.
- Game ends after a set number of customers or turns.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Economy
- Menus
- Fun
- Balance
- Polish

---

# WHAT THIS SECRETLY TEACHES

- economy systems
- menus

---

# OPTIONAL VARIANT

Prices randomly change each turn.
