# NO STRINGS ALLOWED

**Difficulty:** 🔴 Advanced  
**Recommended time:** 30 minutes  
**Players:** 1+  
**Recommended prerequisites:** data structures, numeric/boolean logic  

---

# RULES

- Avoid string values in game state.
- Output text is allowed only where absolutely necessary.
- Use enums/numbers/booleans/other structures for state.
- The game still needs to be understandable.
