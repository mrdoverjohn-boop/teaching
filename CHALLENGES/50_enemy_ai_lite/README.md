# ENEMY AI LITE

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 40 minutes  
**Players:** 1+  
**Recommended prerequisites:** functions, conditions, random  

---

# RULES

- Create an enemy with at least 3 behaviors.
- Behavior changes based on game state.
- Example: attack when healthy, heal when weak, flee sometimes.
- Player must be able to notice different behavior.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Behavior Variety
- Logic
- Fun
- Balance
- Clarity

---

# WHAT THIS SECRETLY TEACHES

- decision logic
- state machines
