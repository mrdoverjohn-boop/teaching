# BROKEN KEYBOARD CHALLENGE

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 35 minutes  
**Players:** 1+  
**Recommended prerequisites:** general coding  

---

# RULES

- Randomly ban 3 non-essential keyboard letters from variable/function names.
- You may still type language keywords normally.
- Your own identifiers cannot contain the banned letters.
- Make a complete tiny game anyway.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Rule Compliance
- Readability
- Fun
- Creativity
- Completeness

---

# WHAT THIS SECRETLY TEACHES

- working under constraints

---

# OPTIONAL VARIANT

Ban one very common identifier letter like e or a.
