# 30 MINUTE GAME CHALLENGE

## WHO

### STUDENTS
- Python
- may work together
- may use the teaching repo

### BRAMITY
- Rust OR C
- works alone

Recommended:
Rust.

---

# SETUP

Before the timer starts, everyone gets up to 5 minutes to:

- open the editor
- create the project
- verify that it runs
- open documentation

NO GAME LOGIC YET.

---

# THEME

Pick one random theme.

Examples:

- ESCAPE
- CATS
- SPACE
- DUNGEON
- ONE BUTTON
- GREMLINS
- SPEED
- EVERYTHING IS BROKEN
- DON'T TOUCH IT

---

# WHAT COUNTS AS A GAME?

It must have:

1. player input
2. a goal
3. some kind of mechanic
4. a way to end

Terminal games count.

---

# TIMER

30 minutes.

At 30:00:

HANDS OFF.

If the game crashes, you may restart it.

You may NOT fix anything after time expires.

---

# OPTIONAL CHAOS RULE

At 15 minutes, reveal ONE extra requirement.

Examples:

- add a random event
- add a score
- add an NPC
- add an item
- add a second ending
- add a turn limit
- add a secret

---

# SCORING

Each game gets 0–5 points in:

- Fun
- Creativity
- Completeness
- Polish
- Technical Cool Shit

Maximum:
25 points.
