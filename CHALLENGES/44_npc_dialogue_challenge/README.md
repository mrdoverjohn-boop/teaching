# NPC DIALOGUE CHALLENGE

**Difficulty:** 🟡 Early  
**Recommended time:** 30 minutes  
**Players:** 1+  
**Recommended prerequisites:** strings, if statements, loops  

---

# RULES

- Create one NPC with at least 8 dialogue responses.
- Player choices must affect future dialogue.
- At least 2 outcomes are required.
- The NPC should have a clear personality.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Dialogue
- Branching
- Personality
- Creativity
- Works

---

# WHAT THIS SECRETLY TEACHES

- dialogue trees
- branching

---

# OPTIONAL VARIANT

NPC remembers one earlier player choice.
