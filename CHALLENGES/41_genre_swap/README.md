# GENRE SWAP

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 45 minutes  
**Players:** 1+  
**Recommended prerequisites:** game design, functions  

---

# RULES

- Take a familiar game concept.
- Turn it into a completely different genre.
- Example: racing game -> turn-based terminal strategy.
- The original concept should still be recognizable.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Transformation
- Creativity
- Fun
- Recognition
- Completeness

---

# WHAT THIS SECRETLY TEACHES

- translating concepts between genres

---

# OPTIONAL VARIANT

Randomly draw both the source concept and new genre.
