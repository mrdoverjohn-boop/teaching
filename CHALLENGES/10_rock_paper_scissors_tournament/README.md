# ROCK PAPER SCISSORS TOURNAMENT

**Difficulty:** 🟢 Beginner  
**Recommended time:** 20 minutes  
**Players:** 2+  
**Recommended prerequisites:** input, if statements, random  

---

# RULES

- Make Rock Paper Scissors against the computer.
- Keep score across multiple rounds.
- First to 5 wins.
- Run a tournament between everyone's versions.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Correctness
- Fun
- Polish
- Creativity
- Tournament Reliability

---

# WHAT THIS SECRETLY TEACHES

- conditions
- game rules
