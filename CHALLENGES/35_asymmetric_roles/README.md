# ASYMMETRIC ROLES

**Difficulty:** 🔴 Advanced  
**Recommended time:** 50 minutes  
**Players:** 2+  
**Recommended prerequisites:** functions, state, design  

---

# RULES

- Players have different abilities or information.
- Each role must matter.
- The game should require interaction between roles.
- Avoid making one role obviously useless.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Role Design
- Balance
- Interaction
- Fun
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- designing different player roles
