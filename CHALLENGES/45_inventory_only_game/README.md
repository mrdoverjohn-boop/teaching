# INVENTORY ONLY GAME

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 40 minutes  
**Players:** 1+  
**Recommended prerequisites:** lists, functions, game state  

---

# RULES

- The main gameplay must happen through inventory decisions.
- No traditional movement system is required.
- Items must interact or have consequences.
- There must be a goal and ending.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Inventory Design
- Strategy
- Creativity
- Fun
- Completeness

---

# WHAT THIS SECRETLY TEACHES

- system-driven design
