# SAVE FILE CHALLENGE

**Difficulty:** 🔴 Advanced  
**Recommended time:** 45 minutes  
**Players:** 1+  
**Recommended prerequisites:** file I/O, functions  

---

# RULES

- Build a tiny game with save and load.
- At minimum save player progress and one resource/stat.
- Closing and reopening the program must preserve progress.
- Handle missing save files cleanly.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Save Reliability
- Load Reliability
- Game Quality
- Error Handling
- Organization

---

# WHAT THIS SECRETLY TEACHES

- persistence
- data serialization

# OPTIONAL VARIANT

Support multiple save slots.
