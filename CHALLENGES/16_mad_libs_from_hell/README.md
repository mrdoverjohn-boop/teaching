# MAD LIBS FROM HELL

**Difficulty:** 🟢 Beginner  
**Recommended time:** 15 minutes  
**Players:** 2+  
**Recommended prerequisites:** input, variables, strings  

---

# RULES

- Ask for at least 8 words.
- Insert them into a ridiculous story.
- Nobody may reveal the story before inputs are collected.
- Funniest final result wins.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Funny Result
- Input Use
- Formatting
- Creativity
- Completeness

---

# WHAT THIS SECRETLY TEACHES

- string composition
- user input

---

# OPTIONAL VARIANT

Teams swap word lists before generating the story.
