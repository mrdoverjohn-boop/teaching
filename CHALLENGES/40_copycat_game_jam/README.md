# COPYCAT GAME JAM

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 45 minutes  
**Players:** 2+  
**Recommended prerequisites:** small-project independence  

---

# RULES

- Pick a very simple existing game concept like Pong, Snake, or a clicker.
- Recreate the core idea without copying code.
- Add one original twist.
- Terminal adaptations are allowed.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Core Recreation
- Original Twist
- Fun
- Polish
- Completeness

---

# WHAT THIS SECRETLY TEACHES

- interpreting mechanics
- implementation

---

# OPTIONAL VARIANT

Everyone recreates the same concept differently.
