# REVERSE ENGINEERING CHALLENGE

**Difficulty:** 🔴 Advanced  
**Recommended time:** 40 minutes  
**Players:** 2+  
**Recommended prerequisites:** functions, debugging, reasoning  

---

# RULES

- Players can run a mystery program but cannot see its source.
- They must recreate its behavior from observation.
- Exact internal implementation does not matter.
- Closest behavior wins.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Behavior Match
- Edge Cases
- Code Quality
- Speed
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- behavioral analysis
- reconstruction

---

# OPTIONAL VARIANT

Only allow 10 test runs of the mystery program.
