# ONE BUTTON GAME

**Difficulty:** 🟡 Early  
**Recommended time:** 30 minutes  
**Players:** 1+  
**Recommended prerequisites:** input, loops  

---

# RULES

- The entire game may use only one gameplay command/button.
- Menus before the game do not count.
- Timing, context, or repeated presses can change what the button does.
- Make the limitation part of the design.
