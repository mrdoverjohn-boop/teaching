# HOT POTATO CODING

**Difficulty:** 🟠 Intermediate  
**Recommended time:** 45 minutes  
**Players:** 3+  
**Recommended prerequisites:** readable code, basic game building  

---

# RULES

- One project rotates between players every 5 minutes.
- Each person must add or improve something.
- Nobody may undo everything the previous person did.
- At the end, play the monster everyone created together.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Team Result
- Integration
- Fun
- Stability
- Creativity

---

# WHAT THIS SECRETLY TEACHES

- team coding
- adaptation

---

# OPTIONAL VARIANT

No talking while the project is rotating.
