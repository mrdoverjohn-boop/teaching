# CHARACTER CREATOR BATTLE

**Difficulty:** 🟢 Beginner  
**Recommended time:** 20 minutes  
**Players:** 2+  
**Recommended prerequisites:** input, variables, basic math  

---

# RULES

- Build a character creator.
- Collect name and at least 4 stats/traits.
- Generate a final character sheet.
- Best combination of useful and funny output wins.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Presentation
- Creativity
- Input Use
- Stats
- Polish
