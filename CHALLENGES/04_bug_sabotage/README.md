# BUG SABOTAGE

**Difficulty:** 🔴 Advanced  
**Recommended time:** 30 minutes  
**Players:** 2+  
**Recommended prerequisites:** debugging, conditions, loops  

---

# RULES

- Build a small working program.
- Swap programs.
- The other person adds exactly 3 fair bugs.
- Return the program.
- Race to find and fix all 3 bugs.

---

# SCORING

Score each category from **0–5** unless your group decides otherwise:

- Bugs Fixed
- Speed
- Explanation
- Code Quality
- No New Bugs

---

# WHAT THIS SECRETLY TEACHES

- debugging
- tracing logic
- reading errors

---

# OPTIONAL VARIANT

One of the bugs must be logic-only: the program runs but behaves incorrectly.
